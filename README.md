# AI 全景学堂｜在线轻量预览版

这是项目的第一版在线轻量预览，包含课程入口、M01-04 核心概念讲解、搜索筛选、明暗主题和互动小测。

## 发布
1. 在仓库 Settings → Pages → Build and deployment → Source 中选择 GitHub Actions。
2. 打开 Actions，等待 Deploy AI Panorama to GitHub Pages 工作流成功。
3. 在 Settings → Pages 点击 Visit site 获取真实网址。

## 重要说明
- 本在线页面是轻量预览版，不等于完整离线 HTML 预览。
- 教材仍在编写和独立审查中，未完成的内容不会冒充正式批准。
- 仓库是公开的，不要提交密码、API Key 或私人资料。
- GitHub Pages 官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
