入门课：模型、产品、平台和应用有什么区别？

一句话记忆：模型是执行计算的组件；产品是你直接使用的服务；平台提供基础能力；应用把模型、数据、工具和流程组合起来完成实际任务。现实中的边界可能重叠，这是一种帮助学习的分类框架，不是对任何公司的内部架构断言。

1. 用会议纪要理解四个层次

  • 模型：把录音转成文字，或根据文字提取摘要和待办事项。
  • 产品：让你上传录音、查看摘要、修改结果的界面。
  • 平台：为开发者提供模型访问、认证、权限、运行环境等基础能力。
  • 应用：把上传、转写、总结、负责人确认和写入任务系统串成完整流程。

2. API 是什么？

API（应用程序编程接口）让一个软件按约定向另一个软件或服务发送请求，并处理返回结果。它不是模型本身，也不等于聊天产品。程序化调用还需要考虑密钥、费用、错误处理、权限和日志。

3. 为什么同一模型的体验可能不同？

产品体验还可能受系统指令、上下文、模型版本、工具、文件权限、联网能力、参数、路由和后处理影响。某产品能联网，并不能单独证明底层模型在所有环境中都自带联网能力。

4. 什么时候用聊天产品，什么时候考虑 API？

  • 个人问答、写作和学习：先考虑现成聊天产品。
  • 每天按固定规则处理大量报告：可评估 API 或自动化工作流。
  • 自动发送消息、修改业务数据或删除文件：先做测试，并保留权限限制、日志和人工确认。

5. 常见误区

  • 产品能做的事，不一定全由模型单独完成。
  • API 不会自动让回答更聪明，也不保证更便宜。
  • 品牌名称不一定能说明具体模型版本和当前功能。

学习原则

先理解，再操作

先用纸上模拟和非敏感示例建立心智模型，再考虑真实 API、自动化或有副作用的工具。

安全底线

不要泄露密钥

不要把 API Key、密码、验证码或私人资料发给 AI，也不要将密钥放进公开网页或前端代码。
