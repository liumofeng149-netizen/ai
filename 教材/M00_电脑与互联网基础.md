# M00｜电脑与互联网基础：先学会看懂数字世界

状态：DRAFT（教学初稿，待独立审查和新手试读）  
预计学习时间：30–45 分钟

## 本课目标
- 区分文件、文件夹、程序、浏览器和网站。
- 说清上传与下载的方向。
- 理解本地设备和云端服务的区别。
- 知道账号密码、验证码和 API Key 为什么不能随意分享。

## 1. 文件与文件夹
把文件想成一份具体材料：照片、PDF、Word 文档、表格和音频都可以是文件。文件夹像收纳盒，用来整理文件。文件名后缀（如 .pdf、.docx、.jpg、.zip、.html）通常提示文件类型，但后缀不能保证内容安全。

例子：下载名为“课程资料.zip”的压缩包后，先确认来源，再解压到单独文件夹。不要因为文件名正常就运行其中的程序。

## 2. 程序、浏览器和网站
- 程序/应用：设备上运行的软件，例如浏览器或文字处理器。
- 浏览器：用来访问网页的程序。
- 网站：通过网络提供的一组网页或服务。
- 网页：浏览器显示的具体页面。

类比：浏览器像交通工具，网站像目的地，网页像目的地里的某个房间。这个类比只用于入门；浏览器和网站实际通过网络协议交换数据。

## 3. 上传和下载
- 上传：从你的设备把文件或数据发送到远端服务。
- 下载：从远端服务把文件或数据保存到你的设备。

上传前先检查是否含有身份证号、住址、合同、私密照片、账号信息或他人的个人资料。不确定时，先制作去标识化样本。

## 4. 本地和云端
本地是主要在手机或电脑上处理、保存；云端则由远端服务器提供存储或计算，通过网络访问。云端方便，但上传通常意味着数据离开设备。使用 AI 网站或 API 时，查看隐私、数据保留和训练使用政策；有密码登录不代表数据绝对安全。

## 5. 账号与密钥
- 密码：用于登录账号。
- 验证码：用于某些登录或验证流程，不能随意转发。
- API Key：让程序获得调用某项服务的权限，有时会产生费用。

底线：不把密码、验证码、API Key 放进公开网页、公开仓库、截图或聊天记录。若意外泄露，立即撤销或轮换密钥，并检查使用记录与费用。

## 6. 常见文件类型
| 类型 | 常见用途 | 注意点 |
|---|---|---|
| .pdf | 阅读、打印文档 | 可能含链接、表单或嵌入内容 |
| .docx | 可编辑文档 | 留意修订记录和隐藏个人信息 |
| .xlsx | 表格与数据 | 公式、宏和外部链接可能带来风险 |
| .jpg / .png | 图片与截图 | 可能含人脸、地址或定位等敏感信息 |
| .zip | 打包文件 | 解压前确认来源，不运行未知程序 |
| .html | 网页文件 | 可在浏览器打开，但不代表可信或安全 |

## 7. 练习
### 选择题
“我把一份文件上传到 AI 网站，请 AI 帮我总结。”哪项最准确？
- A. 文件仍只存在手机，从未离开设备。
- B. 文件或其中的数据可能发送到远端服务，应先检查敏感信息与服务政策。
- C. 只要网站有登录按钮，就不用考虑隐私。

答案：B。上传通常会把数据发送到远端服务，具体处理方式取决于服务实现与政策。

### 操作题
在手机或电脑上创建“AI学习练习”文件夹，放入一份不含个人信息的练习文档，再复制并重命名。确认原文件与副本的位置。设备操作步骤不同的情况，后续按 Android、Windows、macOS 分别补充。
