# M01-04｜模型、产品、平台和应用的区别

本课程是 DRAFT，尚待独立审查与新手试读。

## 一句话解释
模型是执行推断或生成等计算的组件；产品是用户直接使用的服务；平台提供可供其他应用或开发者使用的基础能力；应用则围绕实际任务把模型、数据、工具和流程组织起来。

## 生活类比与边界
把 AI 服务想成餐厅：模型像厨房中的核心处理能力，产品像顾客看到的服务，平台像基础设施，应用像为具体目标设计的完整流程。但真实 AI 系统并不是餐厅，实际边界可能重叠；此分类是教学框架，不是对厂商内部架构的断言。

## 会议纪要案例
- 模型或服务将录音转成文字。
- 模型根据文字生成摘要并提取待办。
- 产品提供上传、查看和修改结果的界面。
- 应用将转写、总结、负责人确认和任务系统写入串成流程。
- API 可让软件按约定请求其他服务并处理响应。

## 关键区别
API 不是模型本身，也不等于聊天产品。API 适合程序化集成，但不会自动让答案更聪明，也不保证更便宜。真实工作流需要费用预算、密钥管理、日志、权限、错误处理和人工确认。

## 小测
产品可以联网搜索，是否能证明底层模型在所有环境下都自带联网能力？不能。联网可能由产品或应用额外接入工具提供。
