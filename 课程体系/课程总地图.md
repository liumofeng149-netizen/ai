# AI 全景学堂课程总地图（规划版）

版本：0.1.0；状态：课程结构草案，待用户试读与独立审查。
目标读者：几乎没有编程或 AI 使用经验、愿意逐步学习的普通人。

## 教学目标
1. 解释 AI、生成式 AI、模型、产品、API、知识库和 Agent 的基本区别。
2. 写出清晰任务说明，要求 AI 说明不确定性，并核验重要事实。
3. 按任务、质量、价格、隐私和可用性选择工具。
4. 读懂基础 API 请求/响应示例，识别密钥、权限、费用和错误风险。
5. 用低风险方式搭建简单知识库或自动化流程，知道何时必须人工确认。
6. 识别过度承诺、虚构来源、提示注入、数据泄露和自动化副作用。

## 课程模块
| 模块 | 名称 | 核心问题 | 验收 |
|---|---|---|---|
| M00 | 电脑与互联网基础 | 文件、浏览器、网站、上传下载、账号和云服务是什么？ | 能找到文件并识别基本隐私风险 |
| M01 | AI 基础概念 | AI、机器学习、深度学习、生成式 AI 有何关系？ | 能用生活例子解释并指出类比边界 |
| M02 | 模型、产品、平台、应用 | 为什么产品功能不等于模型单独能力？ | 能拆分层次并标注不确定部分 |
| M03 | 选择 AI 工具 | 如何按任务、质量、价格、隐私与可用性选工具？ | 使用统一评估表，不把品牌名当能力证明 |
| M04 | 清晰表达任务 | 如何提供目标、背景、材料、约束和验收标准？ | 把模糊需求改写为可执行说明 |
| M05 | Token、上下文与记忆 | 模型一次能处理什么？“记住”意味着什么？ | 区分上下文、产品记忆、检索和训练 |
| M06 | 文件、图像与多模态 | 如何处理文档、图片、音频？ | 能选择合适输入并保护敏感信息 |
| M07 | API 入门 | 请求、响应、JSON、密钥、费用和错误是什么？ | 能读懂模拟请求，不在前端暴露密钥 |
| M08 | 检索与知识库 | 如何让回答基于一组文档？ | 理解切分、检索、引用、更新和权限 |
| M09 | 工作流与自动化 | 如何把多个步骤可靠串起来？ | 设计错误处理、日志和人工确认 |
| M10 | Agent 与工具调用 | 什么是能规划并调用工具的系统？ | 理解权限范围、停止条件和副作用 |
| M11 | 安全、隐私与版权 | 哪些信息不能输入？如何避免误用输出？ | 完成威胁清单与安全检查表 |
| M12 | 小项目实战 | 如何把真实问题拆成可验收的小项目？ | 交付说明、测试用例、失败处理与复盘 |

## 每课固定结构
1. 本课目标；2. 先备知识；3. 生活化解释并说明类比边界；4. 分步骤讲解；5. 完整案例；6. 常见误区与反例；7. 安全提醒；8. 互动练习；9. 参考答案与评分标准；10. 官方延伸阅读；11. 版本与审查记录。

## 学习路线
- 入门：M00 → M01 → M02 → M04 → M03
- 日常使用：M04 → M05 → M06 → M11
- 开发：M00 → M02 → M07 → M08 → M09 → M10 → M12
- 安全：M00 → M03 → M05 → M07 → M08 → M09 → M10 → M11

## 课程状态
- PLANNED：只有标题和目标。
- DRAFT：正文初稿，未经完整审查。
- REVIEW：由另一名审查者按清单检查。
- PILOT：目标读者试读并记录问题。
- APPROVED：来源、事实、练习、无障碍与试读问题均通过验收。
- NEEDS_UPDATE：产品信息过时或发现错误，需修订。

不能因为文件已写入仓库、网站能打开或 AI 说“完成”就标记 APPROVED。
