# AI 全景学堂｜发布验收清单

版本：0.1.0。用途：防止把草稿、可运行、可访问和质量合格混为一谈。

## A. 教材验收
- [ ] 学习目标具体，读者知道学完能做什么。
- [ ] 术语首次出现时有白话解释。
- [ ] 类比说明边界，避免误导。
- [ ] 可变化事实有官方来源与核验日期。
- [ ] 事实、建议、推断和示例清楚区分。
- [ ] 至少包含一个完整案例和一个反例。
- [ ] 有练习、答案和评分标准。
- [ ] 涉及安全、隐私、版权和费用时有提醒。
- [ ] 第二审查者独立提出并关闭问题。
- [ ] 至少一位目标读者试读，问题有记录与处理。
- [ ] 课程状态与证据一致。

## B. 网站验收
- [ ] 手机窄屏无横向溢出。
- [ ] 标题层级正确，正文对比度足够。
- [ ] 关键操作可用键盘操作，控件有清楚名称。
- [ ] 搜索过滤准确，清除按钮恢复全部课程。
- [ ] 明暗主题切换可用。
- [ ] 小测未选择、正确、错误三种状态均有反馈。
- [ ] 外链可访问，打开新窗口时有合理安全属性。
- [ ] HTML 与 JavaScript 语法检查通过。
- [ ] 没有前端密钥、密码或私密资料。
- [ ] 真实手机浏览器人工冒烟测试完成。
- [ ] GitHub Actions 部署成功，发布 URL 实际可打开。

## C. 发布状态
- DRAFT：有初稿。
- REVIEW：审查正在进行。
- PILOT：有真实试读。
- APPROVED：必需项全部完成。
- BLOCKED：存在阻塞项，必须说明原因。
- NEEDS_UPDATE：内容因事实变化或发现问题需更新。
